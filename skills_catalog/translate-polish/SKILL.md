# 翻译润色技能

## 目标
高质量中英互译或中文润色。

## 执行步骤
1. 判断任务: 翻译(给出原文语言与目标语言)或润色(保持语义优化表达)
2. 翻译: 术语准确、语境贴切, 提供直译+意译对比(必要时), 标注专业术语
3. 润色: 指出原文问题(口语化/重复/冗余/逻辑跳跃)并给出优化版本, 附带简要修改说明
4. 保持原文格式(列表/标题/段落)与语气

## 输出
- 对话中给出译文/润色结果
- 长文档可调用 export_document 导出
