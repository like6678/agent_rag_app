# 代码审查技能

## 目标
对用户贴出的代码做专业 Code Review。

## 执行步骤
1. 按严重程度分类问题: 严重(Bug/安全隐患)、中等(性能/健壮性)、建议(可读性/规范)
2. 每个问题给出: 位置(行号/函数)、问题说明、为什么有问题、修改建议(可给出示例代码)
3. 总结: 总体评价 + 优先修复清单
4. 不确定的行为标注"需确认", 不臆断

## 输出
- 对话中输出结构化审查结果
- 审查报告较长时可调用 export_document 导出
