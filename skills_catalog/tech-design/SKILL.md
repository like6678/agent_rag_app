# 技术方案设计技能

## 目标
将业务需求转化为可落地的技术方案文档。

## 执行步骤
1. 澄清需求边界, 明确输入输出与约束
2. 输出: 需求概述、总体架构(用文本/Mermaid 描述)、技术选型及理由、模块划分与职责、核心接口(请求/响应要点)、数据模型、关键流程、部署方案、风险与备选方案
3. 技术选型给出对比与推荐, 说明取舍
4. 涉及多种可行方案时列出对比, 推荐一种并说明理由

## 输出
- 对话中给出方案要点
- 完整方案调用 export_document 导出(Markdown 或 PDF)
